# Milestones

This is a capability roadmap, not an implementation queue. Revisit its order and design as evidence changes.

| Milestone | Capability | Exit criteria |
| --- | --- | --- |
| 1. Interactive camera | Camera movement and input in the sandbox | Input moves a camera predictably. |
| 2. Explore a voxel scene | A player can fly through and inspect a small, static voxel world. | A generated or hard-coded voxel chunk is visible; camera movement makes its 3D scale and depth obvious. |
| 3. Change the voxel scene | A player can directly alter that world. | The player can target one voxel and remove or place one; the changed result is visible immediately. |
